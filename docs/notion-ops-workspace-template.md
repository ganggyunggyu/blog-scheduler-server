## DB 1. 일일 운영 런

용도: 하루 운영 단위를 묶는 상위 DB임.

| 속성 | 타입 | 예시 |
| --- | --- | --- |
| 날짜 | Date | 2026-04-29 |
| 봇 | Select | 블로그, 카페봇 |
| 도메인 | Select | 안과, 알리바바, 애견, 흑염소, 카페 |
| 런 이름 | Title | 04/29 안과 보강 |
| 상태 | Status | 계획, 진행중, 검증중, 완료, 실패, 보류 |
| 목표 건수 | Number | 6 |
| 완료 건수 | Number | 6 |
| 실패 건수 | Number | 0 |
| 담당 | Person |  |
| 시작 시간 | Date |  |
| 종료 시간 | Date |  |
| Source of Truth | Multi-select | Naver UI, DB, RSS, Cafe UI |
| 관련 작업 | Relation | 작업 큐 DB |
| 운영 메모 | Text |  |

추천 뷰:

- 오늘 런: 날짜가 오늘이고 상태가 완료가 아닌 것
- 도메인별 보드: 도메인 기준 Kanban
- 실패/보류: 상태가 실패 또는 보류

## DB 2. 작업 큐

용도: 블로그 발행, 수정, 이미지 보강, 카페 작업까지 모두 한 줄씩 관리함.

| 속성 | 타입 | 예시 |
| --- | --- | --- |
| 작업명 | Title | copy11525 수출대행 즉시 발행 |
| 날짜 | Date | 2026-04-29 |
| 봇 | Select | 블로그, 카페봇 |
| 작업 종류 | Select | 발행, 예약, 수정, 이미지보강, 댓글, 카페글, 확인 |
| 도메인 | Select | 안과, 알리바바, 카페 |
| 계정 | Relation | 계정 DB |
| 키워드 | Relation/Text | 수출대행 |
| 상태 | Status | 대기, 생성중, 발행중, 예약됨, 발행완료, 확인완료, 실패 |
| 예약시각 KST | Date | 2026-04-29 00:00 |
| 완료시각 KST | Date | 2026-04-29 09:45 |
| URL | URL | https://blog.naver.com/... |
| Schedule ID | Text | sch_... |
| Job ID | Text | job_... |
| 이미지 확인 | Select | 미확인, 정상, 부족, 불필요 |
| 메타데이터 확인 | Select | 미확인, 정상, 부족, 불필요 |
| UI 실확인 | Checkbox | true |
| 증거 | Files/URL | 스크린샷 또는 URL |
| 에러 | Text |  |
| 다음 액션 | Text |  |

추천 뷰:

- 오늘 작업: 날짜가 오늘
- P0 미처리: 상태가 실패/대기/발행중이고 오늘 날짜
- 블로그 발행 보드: 상태 기준 Kanban
- 이미지 보강 큐: 작업 종류가 이미지보강
- 카페봇 오늘 작업: 봇이 카페봇
