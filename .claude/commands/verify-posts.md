# 오늘 발행글 검증

오늘 날짜 기준 각 active 계정이 기대 개수만큼 실제 발행됐는지 RSS로 검증합니다.

## 검증 기준

| 카테고리 그룹 | 기대 발행 수/일 |
|---|---|
| 안과, 에스앤비안과, 에스앤비안과-백업 | **3개** |
| 그 외 전부 | **2개** |

## 실행

```bash
npx tsx scripts/verify-today-posts.ts
```

- MongoDB `cafe-bot.accounts`에서 active 계정 전체 조회
- 각 블로그 RSS로 오늘 발행글 수 확인
- OK / UNDER / RSS_FAIL 분류
- **문제 계정만** 출력

## 보고 형식

문제가 있는 경우만 아래처럼 정리:

```
=== {날짜} 발행글 검증 ===
전체 N개 계정 | OK: N | 문제: N

--- 문제 계정 ---
  [미달] 닉네임 (blogId) [카테고리]: 실제/기대
  [RSS실패] 닉네임 (blogId) [카테고리]: 0/기대
```

전체 OK면: "전 계정 정상 발행 완료"

## 주의

- **예약 발행 시간이 모두 지난 후(19시 이후)** 실행해야 정확함
- RSS 실패 계정은 `https://m.blog.naver.com/{blogId}` 에서 수동 확인 필요
