# 오늘 발행글 검증

전 계정 블로그를 방문하여 오늘 발행된 글 수와 카테고리를 검증합니다.

## 검증 기준

| 카테고리 그룹 | 기대 발행 수/일 |
|---|---|
| 안과, 에스앤비안과, 에스앤비안과-백업 | **3개** |
| 그 외 전부 (흑염소, 도그마루 글밥, 서리펫, 추상의구체화, 윤슬) | **2개** |

## 실행 흐름

### 1단계: 검증 스크립트 실행

```bash
npx tsx scripts/verify-today-posts.ts
```

- MongoDB `cafe-bot.accounts`에서 active + category 있는 계정을 전부 조회
- 각 블로그 RSS → 실패 시 Playwright(headless)로 공개 페이지 스크래핑
- 오늘 날짜 기준 발행글 수/제목/블로그카테고리 수집
- 결과를 OK / UNDER / OVER / ERROR로 분류

### 2단계: 결과 해석

스크립트 출력을 읽고 아래 형식으로 사용자에게 보고합니다:

```
=== 오늘({날짜}) 발행글 검증 결과 ===

| 상태 | 계정 | 카테고리 | 실제/기대 | 비고 |
|------|------|---------|----------|------|
| ✓ | 겨울의 눈꽃 | 도그마루 글밥 | 2/2 | |
| ✗ | 에스앤비안과 1 | 안과 | 1/3 | 미달 |
| ... | ... | ... | ... | ... |

전체: {N}개 / OK: {N} / 미달: {N} / 초과: {N} / 에러: {N}
```

### 3단계: 문제 계정 추가 확인 (UNDER/ERROR만)

미달 또는 에러인 계정이 있으면 **OpenClaw 브라우저**로 직접 확인합니다:

1. `openclaw browser open https://m.blog.naver.com/{blogId}`
2. `openclaw browser snapshot`으로 최근 글 목록 확인
3. 오늘 날짜 글이 실제로 몇 개인지 재확인

### 4단계: 최종 보고

- 전체 OK면: "전 계정 정상 발행 확인됨냥"
- 문제 있으면: 문제 계정 목록 + 추가 확인 결과 + 조치 제안

## 참고

- 계정 source of truth: MongoDB `cafe-bot.accounts` 컬렉션
- 교체 예정 계정(isActive=false)은 자동 제외
- 스크립트는 공개 블로그 접근이라 로그인 불필요
- RSS가 비활성인 블로그는 Playwright headless로 자동 폴백

## 주의: 실행 시점

**반드시 예약 발행 시간이 모두 지난 후(저녁 19시 이후)에 실행해야 합니다.**
아침/오후에 돌리면 예약글이 아직 발행 전이라 "미달"로 오판하고, 보충 스케쥴을 넣으면 중복 발행됩니다.
